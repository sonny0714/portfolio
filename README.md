# Research Portfolio

**QoE-Driven Control of Models and Algorithms under Environment Shift**

Two control targets for QoE (quality of experience): model input (transmission rate, frame quality) and model adaptation; under drift an operating agent selects the tool or scheduler

① Reinforcement Learning — Resource Management & Remote Model Serving · ② Agentic AI — LLM Agents for System Operation (Robotics & V2G) · ③ Systems Engineering — Simulators, Testbeds, Protocols & Deployment
